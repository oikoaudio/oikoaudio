# Security policy

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/oikoaudio/oikoaudio/security/advisories/new). Do not open a public issue for it. Include the plugin, version, host, operating system and the steps that trigger the problem. A crafted preset, project state or tuning file that crashes a host or runs code counts as a vulnerability.

Only the latest release of each plugin gets fixes. The plugins are in public beta, so a fix ships in a new beta release rather than as a patch to an older one.

Builds are not signed, and macOS builds are not notarized. Download them only from [oikoaudio.com](https://oikoaudio.com/downloads/) or this repository's releases, and check them against the release's `checksums.txt`.
