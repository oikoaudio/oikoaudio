# Quick guide

Inton sends tuning to MTS-ESP instruments in your DAW. It does not make sound itself. Open a compatible instrument, enable its MTS tuning option if needed, and play it.

## Choose a scale

Click the folder icon to open the Library. With one scale loaded, clicking a preset changes the tuning immediately. Type in search to find a scale. Up and Down move into the list; the arrows beside the tabs step through the results.

Click the folder again or press Escape to close the Library.

## Hear the difference

Choose Listening guide in the funnel's category menu for a small collection of scales to explore. Playing ideas below the scale information opens a listening suggestion when one is available.

Try chords with a sawtooth patch. Small tuning changes can be hard to hear with low sine tones. Return to 12 EDO to compare with ordinary twelve-note equal temperament.

## Use a Scale set

The list icon opens Scale set. Drag a Library preset onto that tab to add it without changing the active tuning. Or click the dashed + row to browse for another scale.

Click a slot's dot or double-click its row to activate it. The arrows beside the tabs step through occupied slots. Automate Set position in your DAW to select slots during playback. Morph sets how long tuning changes take.

Use a slot's circular-arrows button to choose a replacement. Drag rows to reorder them. The × clears a slot; gaps stay when later slots need to keep their automation numbers. The trash button clears the set and keeps the active tuning.

Undo and Redo are at the upper right of the grey panel. Your DAW project saves the scales and their slot assignments.

## Edit and transpose

Close the Library and click the cog beside the scale title to edit a copy. Apply saves your changes; Cancel discards them. The original Library file stays unchanged.

The footer's Hz value sets the reference frequency. Transpose shifts the whole tuning by semitones. The link icon shows connected MTS receivers. If Tuning blocked appears, check for another active MTS master before using the recovery controls.

## Zoom and help

Click oiko audio or right-click the header for zoom and the full Listening guide. The moon or sun changes the theme.
